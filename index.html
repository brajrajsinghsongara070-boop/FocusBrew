FAQ

Common questions

Do I need to create an account?
No account needed at all. Open the app and start studying immediately.
Does it work without internet?
Yes! FocusBrew is a PWA. Once loaded it works fully offline. Install it to your home screen for the best experience.
Is it really free forever?
Yes. The core app — timer, tasks, streaks, subjects — is free forever with no ads.
Can I install it on my phone?
Yes! Android: Chrome → Add to Home Screen. iPhone: Safari → Share → Add to Home Screen. Works like a native app.
Play Store version kab aayega?
Play Store version jald aa raha hai TWA (Trusted Web Activity) ke zariye. Abhi ke liye website se seedha install karein — same experience hai!
